# Возможности оконных функций
## Задачи которые решатся с помощью оконных функций
- **Ранжирование** - рейтинги
- **Сравнение со смещением** - соседние элементы и границы
- **Агрегация** - сумма и среднее
- **Скользящие агрегаты** - сумма и среднее в динамике

## Как поставить ранг
```
window w as (order by salary desc)
```
- window - слово, которое показывает что дальше будет определение окна
- w - название окна (любое) 
- (order by salary desc) - описание окна 

## Как посчитать ранг по окну w
```
dense_rank() over w
```
Это оконная функция, которая считает ранг о указанному окну

Конструкция window сама по себе ничего не делает с результатами запроса. Она только определяет окно, которое можно использовать (или не использовать) в запросе. Если убрать вызов dense_rank(), запрос отработает, как будто нет никаких окон. Окно начинает работать только тогда, когда в select появляется оконная функция, которая его использует.

### Oracle и SQL Server не поддерживают window. Нужно перенести описание внутрь инструкции over
```
select
dence_rank() over(
order by salary desc
) as rank,
name, department, salary
from employees
order by rank;
```

### Нескоько окон
```
select...
from...
where...
window
w1 as (...),
w2 as (...),
w3 as (...)
```

## Функции ранжирования
- row_number() - порядковый номер строки
- dense_rank() - ранг строки
- rank() - ранг, но с пропусками
- ntile() - разбивает все строки на n групп и возвращает номер группы, в которую попала строка
