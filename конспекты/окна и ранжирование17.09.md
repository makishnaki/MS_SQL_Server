# Возможности оконных функций
## Задачи которые решатся с помощью оконных функций
- **Ранжирование** - рейтинги
- **Сравнение со смещением** - соседние элементы и границы
- **Агрегация** - сумма и среднее
- **Скользящие агрегаты** - сумма и среднее в динамике

## Как поставить ранг
```
window w as (order by salary desc)
```
- window - слово, которое показывает что дальше будет определение окна
- w - название окна (любое) 
- (order by salary desc) - описание окна 

## Как посчитать ранг по окну w
```
dense_rank() over w
```
Это оконная функция, которая считает ранг о указанному окну

Конструкция window сама по себе ничего не делает с результатами запроса. Она только определяет окно, которое можно использовать (или не использовать) в запросе. Если убрать вызов dense_rank(), запрос отработает, как будто нет никаких окон. Окно начинает работать только тогда, когда в select появляется оконная функция, которая его использует.

### Oracle и SQL Server не поддерживают window. Нужно перенести описание внутрь инструкции over
```
select
dence_rank() over(
order by salary desc
) as rank,
name, department, salary
from employees
order by rank;
```

### Нескоько окон
```
select...
from...
where...
window
w1 as (...),
w2 as (...),
w3 as (...)
```

### Поддержка в СУБД:
* **Поддерживают именованные окна:** MySQL, ClickHouse.
* **Не поддерживают конструкцию `WINDOW`:** Oracle, MS SQL Server. В этих СУБД описание окна необходимо переносить напрямую внутрь `OVER (...)`:
  ```sql
  SELECT dense_rank() OVER (ORDER BY salary DESC) AS rank, ...
  ```

## 2. Использование нескольких окон

Если в запросе требуется посчитать ранги по разным критериям, несколько именованных окон перечисляются в блоке `WINDOW` через запятую.

```sql
SELECT 
    dense_rank() OVER w1 AS r_asc,
    dense_rank() OVER w2 AS r_desc,
    name, salary
FROM employees
WINDOW 
    w1 AS (ORDER BY salary ASC),
    w2 AS (ORDER BY salary DESC)
ORDER BY salary, id;
```

## 3. Секции окна, группировка внутри окна

С помощью инструкции `PARTITION BY` можно разбить окно на независимые изолированные секции (например, для подсчета рейтинга отдельно внутри каждого департамента).

```sql
WINDOW w AS (
    PARTITION BY department 
    ORDER BY salary DESC
)
```
* При переходе от одной секции (департамента) к другой расчет ранга **сбрасывается обратно на 1**.

## 4. Основные функции ранжирования

| Функция | Описание | Особенности |
| :--- | :--- | :--- |
| `row_number()` | Порядковый номер строки. | Просто нумерует строки подряд (`1, 2, 3...`). |
| `dense_rank()` | Ранг строки (плотный). | Одинаковые значения получают один ранг. Следующий ранг идет **без пропусков** (`1, 2, 2, 3...`). |
| `rank()` | Ранг строки (с пропусками). | Одинаковые значения получают один ранг. Следующий ранг **пропускает номера** по числу дублей (`1, 2, 2, 4...`). |
| `ntile(n)` | Распределение по группам. | Разбивает строки на `n` равных групп и возвращает номер группы (`1, 2, 3...`). |

### Нюансы работы `ntile(n)`:
* Если общее количество строк не делится нацело на количество групп, то **первые группы будут крупнее** последующих.
* Функция стремится сделать группы одинаковыми по размеру, из-за чего строки с **абсолютно одинаковыми значениями** могут случайно попасть в разные (соседние) группы.


## Функции ранжирования
- row_number() - порядковый номер строки
- dense_rank() - ранг строки
- rank() - ранг, но с пропусками
- ntile() - разбивает все строки на n групп и возвращает номер группы, в которую попала строка
