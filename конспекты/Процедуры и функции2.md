# Хранимые процедуры, функции и динамический SQL в MySQL

## 1. Готовые инструкции Prepared Statements

**Prepared Statements** позволяют динамически собирать SQL-запрос из строки, безопасно передавать в него параметры и выполнять на сервере (аналог функции `eval()` с защитой от SQL-инъекций).

### Основной синтаксис:
1. **`PREPARE stmt_name FROM 'sql_строка';`** — компиляция инструкции.
2. **`EXECUTE stmt_name [USING @var1, @var2];`** — выполнение. Переменные подставляются вместо знаков `?` в запросе.
3. **`DEALLOCATE PREPARE stmt_name;`** — удаление инструкции из памяти сервера.

### Пример (Вычисление гипотенузы):
```sql
PREPARE stmt1 FROM 'SELECT SQRT(POW(?,2) + POW(?,2)) AS Гипотенуза';
SET @a = 3;
SET @b = 4;
EXECUTE stmt1 USING @a, @b; -- Выведет: 5
DEALLOCATE PREPARE stmt1;
```

> **Практическое задание из презентации:** Создать готовую инструкцию для ввода значений в таблицу `Students`:
> ```sql
> PREPARE insert_student FROM 'INSERT INTO students (name, kom) VALUES (?, ?)';
> SET @s_name = 'Иван';
> SET @s_kom = 1;
> EXECUTE insert_student USING @s_name, @s_kom;
> DEALLOCATE PREPARE insert_student;
> ```

## 2. Хранимые процедуры Stored Procedures

**Хранимая процедура** — это скомпилированный набор SQL-команд, хранящийся на сервере.
* **Плюсы:** повторное использование кода, снижение трафика между клиентом и сервером, безопасность данных, независимость бизнес-логики от языка приложения.

### Особенности синтаксиса в MySQL:
Поскольку команды внутри процедуры разделяются точкой с запятой `;`, перед созданием необходимо временно переопределить разделитель запросов утилиты с помощью команды `DELIMITER`.

```sql
DELIMITER $$

CREATE PROCEDURE name_proc (
    IN param1 INT,       -- Входной параметр (значение только для чтения)
    OUT param2 CHAR(5)   -- Выходной параметр (возвращает результат наружу)
)
BEGIN
    SELECT column_name INTO param2 
    FROM table_name 
    WHERE id = param1;
END$$

DELIMITER ;
```
* **Вызов процедуры:** `CALL name_proc(10, @result);`.

## 3. Переменные и управление потоком

### Виды переменных:
1. **Пользовательские (`@имя`)** — объявляются через `SET @var = 1;`. Существуют на протяжении всей текущей сессии подключения.
2. **Локальные переменные кода** — объявляются строго внутри блока `BEGIN...END` с помощью `DECLARE имя тип [DEFAULT значение];`. Уничтожаются после завершения подпрограммы.

### Операторы циклов и условий:
* **Условие `IF`:** `IF условие THEN ... ELSEIF ... ELSE ... END IF;`
* **Цикл `WHILE`:** `WHILE условие DO ... END WHILE;`
* **Цикл `REPEAT`:** `REPEAT ... UNTIL условие END REPEAT;` (Выполняется минимум 1 раз).
* **Управление циклами:** `LEAVE label;` (аналог `break`), `ITERATE label;` (аналог `continue`).

## 4. Курсоры (Cursors) и Обработка ошибок

**Курсор** — это указатель на результирующий набор строк, позволяющий перебирать записи поочередно (только для чтения, медленные, двигаются строго вперед).

### Порядок объявления в блоке `BEGIN...END` (Строгий приоритет):
1. Локальные переменные (`DECLARE var ...`).
2. Курсоры (`DECLARE cur CURSOR FOR ...`).
3. Обработчики ошибок (`DECLARE CONTINUE HANDLER FOR ...`).

```sql
-- Пример перебора строк с обработчиком конца данных (SQLSTATE '02000' или NOT FOUND)
DECLARE done INT DEFAULT 0;
DECLARE s_id INT;
DECLARE cur1 CURSOR FOR SELECT id FROM test_table;
DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = 1;

OPEN cur1;
read_loop: LOOP
    FETCH cur1 INTO s_id;
    IF done THEN LEAVE read_loop; END IF;
    -- Логика обработки строки
END LOOP;
CLOSE cur1;
```

## 5. Хранимые функции (Stored Functions)

В отличие от процедур, функции вызываются напрямую внутри обычных `SELECT` выражений и **обязаны** возвращать строго одно скалярное значение через `RETURN`.

* У параметров функций **запрещено** указывать модификаторы `IN / OUT / INOUT` (все параметры по умолчанию `IN`).

```sql
CREATE FUNCTION factorial (n INT) RETURNS INT
BEGIN
    DECLARE i INT DEFAULT 1;
    DECLARE r INT DEFAULT 1;
    WHILE (i <= n) DO
        SET r = r * i;
        SET i = i + 1;
    END WHILE;
    RETURN r;
END;
```
* **Вызов функции:** `SELECT factorial(5);`.

## 6. Метаданные и Удаление

### Как посмотреть список и код подпрограмм:
* `SHOW PROCEDURE STATUS;` / `SHOW FUNCTION STATUS;` — список всех объектов.
* `SHOW CREATE PROCEDURE имя;` — просмотр исходного кода.
* Запросы к системным таблицам: `information_schema.ROUTINES`.

### Удаление:
* `DROP PROCEDURE IF EXISTS имя_процедуры;`
* `DROP FUNCTION IF EXISTS имя_функции;`
