## 1. Что такое пакет/Batch
**Пакет Batch** — это группа операторов T-SQL, которая отправляется от приложения к СУБД SQL Server для совместного выполнения. 

* СУБД компилирует все операторы пакета в единый план выполнения.

### Разделитель пакетов GO
* Операторы в скрипте разделяются встроенной командой `GO`.
* `GO` — это команда утилит (SSMS, sqlcmd), а не инструкция самого языка T-SQL. Она сигнализирует о завершении текущего пакета и отправке его на сервер.

## 2. Переменные в T-SQL

Переменные используются для временного хранения данных одного определенного типа в рамках одного пакета.

### Ключевое слово `DECLARE`
Используется для объявления одной или нескольких переменных. Для каждой переменной обязательно указывается имя и тип данных.

* **Синтаксис имени:** Имя переменной обязательно должно начинаться с одного символа `@` (например, `@my_variable`).

```sql
-- Пример объявления переменной
DECLARE @EmployeeID INT;
DECLARE @MinSalary MONEY, @MaxSalary MONEY;
```

## 3. Область видимости переменных

Областью видимости локальной переменной является **только тот пакет (batch)**, в котором она была объявлена.

* Переменная «живет» с момента её объявления (`DECLARE`) до конца текущего пакета (до первой команды `GO` или конца процедуры/скрипта).
* Переменная, объявленная в одном пакете, недоступна в следующем пакете.

### Пример нарушения области видимости (вызовет ошибку):

```sql
DECLARE @MyVar INT;
SET @MyVar = 10;
GO -- Конец первого пакета. Переменная @MyVar уничтожена.

SELECT @MyVar; -- Ошибка! Переменная @MyVar не объявлена.
GO
```

## 4. Инициализация и присвоение значений

По умолчанию при объявлении переменная принимает значение `NULL`. Присвоить значение переменной можно несколькими способами:

### Инструкция `SET`
Используется для присвоения переменной конкретного значения или результата выражения. Это стандартный и наиболее читаемый способ для одиночных присвоений.

```sql
DECLARE @Greeting VARCHAR(50);
SET @Greeting = 'Привет, SQL Server!';
```

## 5. Присвоение значения через `SELECT`

Инструкцию `SELECT` можно использовать для присвоения переменной значения, полученного из таблицы БД.

### Важные правила работы с `SELECT` для переменных:
1. Инструкция `SELECT`, присваивающая значение переменной, **не возвращает** результирующий набор данных клиенту.
2. Если запрос возвращает **несколько строк**, переменной будет присвоено значение из **последней** обработанной строки.
3. Если запрос **не возвращает ни одной строки**, переменная **сохраняет свое прежнее значение** (оно не заменяется на `NULL` автоматически, если там уже что-то было).

### Примеры:

```sql
-- Переменная принимает значение из таблицы
DECLARE @EmpName NVARCHAR(50);
SELECT @EmpName = FirstName FROM Employees WHERE EmployeeID = 1;

-- Пример, когда запрос возвращает несколько строк (будет записано последнее значение)
DECLARE @LastName NVARCHAR(50);
SELECT @LastName = LastName FROM Employees; -- Запишется фамилия из последней строки плана
```
