# Базы данных
основы T-SQL

- Пакет - это группа операторов T-SQL, которая обрабатывается сервером СУБД вместе
- DECLARE - объявление используемых переменных, для каждой переменной указывается имя и тип
- Область видимости переменной - являются все инструкции между ее объявлением и концом пакета или хранимой процедуры, где она объявлена
- Операторы присваивания - инициализировать в DECLARE, присвоить значение SET, присвоить значение  SELECT
