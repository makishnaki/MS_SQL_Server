# Функция с примером для всех встроенных функций
![функция](https://github.com/makishnaki/MS_SQL_Server/blob/main/picFolder/bd18.png)

## Строковые функции
 - upper: переводит все буквы в верхний регистр, например из hello в HELLO
 - reverse: переворачивает строку, например из abc в cba
 - len: считает количество символов в слове, например тест = 4
 - CAST: функция явного приведения типов. Превращает число 4 в текст '4'

## Математические функции
 - abs: возвращает модуль числа, например из -5 в 5
 - round: округляет число до указанного количества знаков, например 3,1415 до 3,1400

## Функции даты и времени
 - getdate: возвращает текущую дату и время сервера прямо в секунду выполнения запроса
 - datepart: вырезает из даты указанную часть

## Системные функции
 - suser_name: возвращает имя учетной записи
 - isnull: проверяет первый аргумент на наличие null
