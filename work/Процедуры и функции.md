# Функция с примером для всех встроенных функций
![функция](https://github.com/makishnaki/MS_SQL_Server/blob/main/picFolder/bd18.png)

Функция `dbo.fn_DemonstrateBuiltInFunctions` демонстрирует работу со строковыми функциями (`UPPER`, `LEN`), функциями даты (`YEAR`, `SYSDATETIME`) и математическими функциями (`ABS`).

### Код функции
```sql
CREATE FUNCTION dbo.fn_DemonstrateBuiltInFunctions (@InputString NVARCHAR(100))
RETURNS NVARCHAR(MAX)
AS
BEGIN
    DECLARE @UpperStr NVARCHAR(100) = UPPER(@InputString);
    DECLARE @Length INT = LEN(@InputString);
    DECLARE @CurrentYear INT = YEAR(SYSDATETIME());
    DECLARE @CalcValue INT = ABS(-42);

    RETURN 'Верхний регистр: ' + @UpperStr + 
           ' | Длина: ' + CAST(@Length AS NVARCHAR(10)) + 
           ' | Текущий год: ' + CAST(@CurrentYear AS NVARCHAR(10)) + 
           ' | Число ABS: ' + CAST(@CalcValue AS NVARCHAR(10));
END;
GO
```


## Строковые функции
 - upper: переводит все буквы в верхний регистр, например из hello в HELLO
 - reverse: переворачивает строку, например из abc в cba
 - len: считает количество символов в слове, например тест = 4
 - CAST: функция явного приведения типов. Превращает число 4 в текст '4'

## Математические функции
 - abs: возвращает модуль числа, например из -5 в 5
 - round: округляет число до указанного количества знаков, например 3,1415 до 3,1400

## Функции даты и времени
 - getdate: возвращает текущую дату и время сервера прямо в секунду выполнения запроса
 - datepart: вырезает из даты указанную часть

## Системные функции
 - suser_name: возвращает имя учетной записи
 - isnull: проверяет первый аргумент на наличие null

# Процедура


## 2. Хранимая процедура (Расчет разницы студентов)

Процедура `dbo.sp_CalculateStudentDifference` принимает на вход количество поступивших и выпускающихся студентов, после чего вычисляет и выводит разницу между ними.

### Код процедуры
```sql
CREATE PROCEDURE dbo.sp_CalculateStudentDifference
    @EnrolledCount INT,
    @GraduatedCount INT
AS
BEGIN
    SET NOCOUNT ON;
    DECLARE @Difference INT;
    SET @Difference = @GraduatedCount - @EnrolledCount;

    SELECT 
        @EnrolledCount AS [Поступило студентов],
        @GraduatedCount AS [Выпускается студентов],
        @Difference AS [Разница (Выпускники - Поступившие)];
END;
GO
```
