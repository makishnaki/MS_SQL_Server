# MS_SQL_Server - Теория баз данных. Программирование MS SQL Server

> Репозиторий для дисциплины "Теория баз данных. Программирование MS SQL Server"

## 🌸Структура
* `Homeworks` - Домашние задания
* `picFolder` - Скриншоты для md файлов
* `work` - Работы выполненные на занятиях
* `Контрольные работы` - Проверочные и контрольные работы
* `конспекты` - Конспекты

> Работы выполненные на занятиях, считающиеся домашними заданиями перенесены в Homeworks
