## 2. Обработка ошибок с TRY...CATCH и XACT_ABORT
>перевод денег между счетами внутри конструкции BEGIN TRY ... END TRY / BEGIN CATCH ... END CATCH
![таблица](https://github.com/makishnaki/MS_SQL_Server/blob/main/picFolder/bd73.png)
> у меня все отработало, пришлось делить на ноль чтобы поймать ошибку
![таблица](https://github.com/makishnaki/MS_SQL_Server/blob/main/picFolder/bd78.png)

**SET XACT_ABORT ON**
SQL Server автоматически прерывает выполнение скрипта, если во время транзакции происходит ошибка времени выполнения (runtime error)
он признает операцию обреченной и полностью откатывает

**SET XACT_ABORT OFF**
При возникновении ошибок SQL Server откатывает только ту команду, которая вызвала ошибку, но сама транзакция остается активной.
без try catch он может частично выполнять транзакции
